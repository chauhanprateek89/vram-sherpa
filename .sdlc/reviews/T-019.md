### Nits (do not fail the review)

1. **`tests/test_how_it_works.py`, `test_step_circles_stay_30px_and_links_use_accent`.**
   - **What is wrong:** it restates the CSS text, so it guards against regressions but does not prove the rendered size or colour.
   - **Fixed looks like:** nothing needed now. QA's browser pass is the real proof.
2. **The same test asserts `css.index(".doc a {") > css.index("a:hover {")`.**
   - **What is wrong:** `index` finds only the first `a:hover {`. Today that is the global rule at `styles.css:263`, which is correct, but the check would break if another `…a:hover {` rule were added before it.
   - **Fixed looks like:** anchoring the search to `^a:hover {` in multiline mode would make it robust.
3. **Carried over from review 1: `styles.css:853` and `:856`.**
   - **What is wrong:** `.term code.formula` and `.rule code` still repeat the same declarations.
   - **Fixed looks like:** T-020's cleanup merges them into one selector list.
