**How the browser handles `0`:** in Chromium, typing `0` and submitting is stopped by the browser's own check (`min="1"`, "Value must be greater than or equal to 1."). No request is sent, with or without JavaScript. With JavaScript on, the same happens when a filter is changed, because htmx validates the form first. So through the real UI, a server rejection after page load is reached only by a client that skips constraint validation. Step 3 shows the code handles that case.
