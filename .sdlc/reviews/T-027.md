Covered by `test_page_load_without_hardware_redirects_to_landing` (the four ADR-0010 URLs times no header, `false` and `TRUE`), `test_redirect_ignores_every_other_parameter` and `test_redirect_makes_no_database_query` (a `before_cursor_execute` listener records no statements).

- R-081: `/results/partials/content` with no query still answers `302 Location: /results`, and both hops end on `/` with 200. Covered by `test_old_partial_link_without_query_takes_two_relative_hops_to_landing`.

### Quality issues

None blocking.

- Correctness: the comparison `request.headers.get("HX-Request") != "true"` is exact and case-sensitive, as ADR-0010 requires, and the `TRUE` case is tested. FastAPI's 422 is still raised for an invalid `context_tokens` before the handler runs. The `get_session` dependency opens a session but makes no query, which the listener test confirms.
- Security: the `Location` is the literal `/`. The status is passed explicitly, never Starlette's 307 default, and never a permanent 301 or 308. The redirect sets its own `Cache-Control` and `Vary`, because the `text/html`-keyed middleware skips a response with no body. This matches the ADR-0008 old-link redirect line for line. No new route, GET only (rule 11).
- The tests check behaviour (status, headers, body, number of database queries, the host guard order), not the code's wording.

### Nits

- `src/vramsherpa/main.py:548`: `_has_hardware_input` accepts `str | int | float` through `isinstance`, but all three parameters are declared `str | None`. `value is not None and value.strip()` with `str | None` annotations would be simpler and type-checkable. The current form is harmless.
- `tests/test_r083_redirect.py`, `test_redirect_is_checked_first_in_the_handler_through_the_helper`: it asserts on the handler's source text, including the exact whitespace `'RedirectResponse(\n            "/",'`. That breaks on harmless reformatting. The behavioural tests (`test_redirect_makes_no_database_query`, `test_unknown_host_gets_400_json_without_location`) already cover what matters. Consider keeping only the first-statement check.
