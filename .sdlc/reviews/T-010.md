### Nits (non-blocking)

- `tests/test_ui_markup.py:242-245`: the root check only matches the exact selector `html`. A background on `:root` (the same element), on `html[data-theme=...]`, or on `html` inside an `@media` block (the regex swallows the inner rule) would slip through. Adding `:root` and `html[` prefixes to the check would close that gap.
- `tests/test_ui_markup.py:246`: `_rules(css, "body")[-1]` assumes that the last match for `body` is the bare `body` rule. A later rule ending in `body` (for example `.x body`) would break it. Matching `^body\s*\{` would make it robust.
- `tests/test_brand.py:189`: the set of used values does not include `20261025c`, so nothing stops a revert to it. This is trivial, because `c` was never released.
- Carried over from review 1, all unchanged:

  - `test_glass_has_both_solid_fallbacks` relies on regexes tied to the formatting.
