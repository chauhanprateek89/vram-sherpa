### Nits (do not fail the review)

- `tests/test_packaging.py:35`: `glob(os.path.join(package_dir, pattern), ...)` treats any glob metacharacter in the checkout path (for example `[`) as pattern syntax. setuptools does the same, so the test is faithful. `glob(pattern, root_dir=package_dir, recursive=True)` would be more robust, at a small cost to how literally it mirrors setuptools. Optional.
- `tests/test_packaging.py:30-39`: the matcher does not model `exclude-package-data` or `MANIFEST.in`. Neither is used today. If one is ever added, the guard could pass while the wheel drops a file. A one-line comment saying so would help a future reader. Optional.
