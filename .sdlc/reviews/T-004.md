### Stage 2: code quality

- **Correctness.** The extractor tracks nesting with a tag stack. If an unclosed or mismatched tag appears, it pops through until it finds the matching end tag, so depth stays consistent. `convert_charrefs=True` turns `Won&#39;t fit` back into `Won't fit`. Text chunks are joined with spaces and the whitespace is normalised, so `<b>8.6 GB</b> spare` reads as `8.6 GB spare`, and `&nbsp;` counts as whitespace too. The `Won't fit|Fits|Tight` alternation tries `Won't fit` first. Each pane asserts that it found every field, with a message naming the variant, so a template change that loses a hook fails loudly rather than silently. The computed margin uses the same `>= 0` branch as the template.
- **Tests.** They test behaviour: real HTTP renders compared with a frozen golden file and with the computed context. The computed side has to restate the template's number formats (`%.2f`, `%.1f`), and that is how the criterion defines "equal".
- **Constitution.** Rule 16: verdict, required, available and margin are all asserted per pane. Rule 18: no check is removed or weakened. Rule 19: temp SQLite and no network. Rule 21: no static change. Rules 11, 12 and 15 are not touched. No violations.
- **Simplicity and fit.** The file reads cleanly, the module docstring states the extractor's contract, and there is no dead code.

**Quality issues (blocking):** none.

### Nits (non-blocking)

1. `tests/test_reference_queries.py:82`: the gauge is taken to be the first `role="img"` element in a pane. If a later task gives the verdict shape cue (R-072) its own `role="img"` instead of `aria-hidden`, the test would fail even though the gauge is unchanged. The approved mockup uses `aria-hidden`, so this is not a problem today. Fix: keep the first `role="img"` whose `aria-label` matches `_GAUGE_RE`.
2. `tests/test_reference_queries.py:36`: `_VOID_TAGS` is missing `wbr`, `track` and `param`. The stack recovers on the next ancestor end tag, so this is harmless. Adding them makes the depth tracking exact.
3. `tests/test_reference_queries.py:27, 151-190`: `computed_cards` imports private `main` helpers (`_results_page_context`, `_catalog_version`), builds a raw ASGI `Request`, and copies route defaults (`context_tokens` 2048, the truthy set for `recommended_only`). If a later task refactors these helpers, this test has to change with them. This is acceptable for a test-only task. Mention it in T-008+ handoffs so nobody "fixes" the test by editing the fixture.
