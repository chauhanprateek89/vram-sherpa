It grows with the context length. runtime_overhead_gb: Memory the runtime needs besides the model: a flat 1.0 GB plus 0.05 GB for every billion parameters. required_vram_gb: Everything the variant needs: weights, KV cache and runtime overhead added up. Decisions for you

1. Logo

I merged D and E: D’s tile arrangement drawn in E’s glass and gradients. It is neither D’s four tiles nor E’s two squares. Tell me if you would rather keep one of the originals.

2. GPU suggestion list (Q-8)

I could not test iOS Safari or Android Chrome, so I have no evidence that the native list works badly on phones. The mockups keep the native list, which is the default in ADR-0005. The state “GPU suggestions” shows the styled replacement if you want it.

3. Filters closed on desktop, inside the form tile

Tab order has to match the screen (R-077) and the filters have to stay outside the refreshed results, so they sit at the foot of the form tile. Opened by default on desktop, they would push the first verdict to past 1,100 px at 1280, past the 800 px limit, so the mockups keep them closed at both widths.
