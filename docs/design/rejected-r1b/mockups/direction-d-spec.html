Direction D: Bento

A bento grid. Every block of the page is a tile with its own size and job, and the answer tile is the biggest.

Mark, dark theme

Favicon at 64, 32 and 16 px

Same file in a dark tab bar

Concept. Packed tiles. Three filled tiles and one outlined slot: models packed into a memory budget, with the outlined bay as the spare room. The same four shapes are the bento grid the page is built on.

Favicon. The same four tiles, drawn on a 32 px grid with 2 px gaps. At 16 px the slot reads as a gap, which is acceptable: it is the one tile that is not filled.

Files: docs/design/marks/direction-d-mark.svg (header mark, uses currentColor tokens in the build), direction-d-favicon.svg (switches colour with prefers-color-scheme), per ADR-0003. PNG exports (32 px and 180 px) are made from the chosen favicon in the build task.

Typography

Bricolage Grotesque, SIL Open Font License 1.1. Self-hosted: bricolage-grotesque-latin-opsz-normal.woff2 (76.9 KB, Latin subset, one file). Loaded with font-display: swap; fallback stack ui-sans-serif, system-ui, -apple-system, Segoe UI, Roboto, sans-serif. No request to a font host (ADR-0002).

Variable axes. opsz 12 to 96 (optical size, set automatically from font-size with font-optical-sizing: auto, so the 46 px headline gets the tight display cut and the 14 px caption gets the sturdy text cut); wght 200 to 800.

Weights used. 400 body, 600 labels and nav, 650 pick names and buttons, 680 card titles and verdicts, 700 headline and form title, 720 big figures.

Glass and blur

None. Direction D uses no backdrop-filter anywhere, so it costs a phone nothing extra. Answer tile glow is a static radial-gradient (17% of the verdict colour), not a blur.

Phone cost. Single column. The form tile puts VRAM and the context switch on one row. The answer tile follows at once. Top Picks collapse to one 56 px row. Filters collapse to one 56 px row. All four quantisation buttons share one row (4 x 80 px).

Blurred layers. 0 blurred layers on any width.
